Event theory

    -event is an action that happen in browser e.g clicking a button,moving mouse,pressing key,submitting form,loading page
    -js can detect these events and respond to them
    -types of event ->1> mouse event - click, dbl click, mouse over, mouse out-(types).
                2> keyboard event - key down, key up 
                3> browser event - load, scroll, resize

    # onclick="alert('photoshop')" -> Html should contain structure js should contain logic ,so mixing both is bad practice hard to maintain in big project

    # problem -> only one event can be assighned cannot handle multiple listeners properly

    # adv way -> document.getElementById('Nature').addEventListener('click',function(e){console.log(e);},false)

    (imp)addEventListener - addEventListener is a js method used to attach an event handller to an html element so that specific function run when a perticular event occures

                        false(event  propagation) - child to parent
