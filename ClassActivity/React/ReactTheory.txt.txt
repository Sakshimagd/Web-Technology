react is a js library developed by meta to build a fast and interactive user interfaces.
By using javascript: It is a single page application(spa - page does not reload only contain change . ex - Instagram, facebook) 

why do we use react:
    problem with traditional js:
          fully page reload
          complex dom manipulation
          hard to manage large applications
    with react :
          updates only required part
          use only reusable components

Virtual DOM : react cretes a copy of real DOM means virtual DOM. when data changes react updates virtual DOM. Updates only change the part in real dom
    use : high performance
